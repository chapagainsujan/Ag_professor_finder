# Student intake

Turn a CV or a few sentences into a search profile. Extract, do not invent.

## Extract these fields

| Field | Notes |
|---|---|
| Name, current institution, country | |
| Highest degree, field, year, GPA or class if listed | Copy as written |
| Thesis or final-year project | Title, topic, methods, supervisor if listed |
| Core topic | e.g. wheat scab resistance, soil carbon, post-harvest storage |
| Crops / systems / organisms | Use the names the student uses |
| Methods and lab skills | PCR, field trials, GIS, R, Python, HPLC, greenhouse work, survey design |
| Tools and software | R, SAS, QGIS, ArcGIS, Python, Excel, etc. |
| Publications, posters, talks | Full citation if any |
| Work and field experience | Extension, NGO, seed company, farm |
| Awards, language tests | IELTS/TOEFL/Duolingo, GRE if taken |
| Goal | MSc, PhD, RA, visiting |
| Funding need | Full funding required, partial, self-funded |
| Target countries and start term | |

## Questions to ask (only if the answer is not in the material)

Pick at most four:
1. MSc or PhD, and which intake do you want to start in?
2. Do you need a funded position, or can you pay some costs?
3. Which of US, Canada, Australia, or all three?
4. If you could only study one thing for the next three years, what is it?

## Keyword expansion

From the core topic, write 6 to 10 search phrases:
- the plain phrase ("wheat head blight")
- the scientific phrase ("Fusarium head blight resistance")
- the crop plus method ("wheat genomic selection")
- neighboring topics a professor might label the work as ("mycotoxin", "DON accumulation")
- the problem framing ("climate-resilient cropping systems")

Save them in the profile. Use them verbatim in searches and in funder databases.

## Agriculture subfield map

Use to widen or narrow:

- Plant breeding and genetics, genomics, pre-breeding, genomic selection, QTL, phenotyping
- Plant pathology, mycology, nematology, disease resistance, epidemiology
- Entomology, integrated pest management, pollinators, biocontrol
- Agronomy, cropping systems, cover crops, weed science, crop physiology
- Soil science, soil health, nutrient cycling, carbon, microbiome
- Horticulture, vegetable and fruit crops, protected cultivation, postharvest
- Irrigation, water management, hydrology, drought
- Precision agriculture, remote sensing, ag robotics, ag engineering, digital agriculture
- Animal science, nutrition, genetics, welfare, dairy, poultry, aquaculture
- Food science, food safety, mycotoxins, processing
- Agricultural economics, policy, value chains, extension, rural development
- Climate adaptation, agroecology, organic systems

## Profile summary to show the student (5 lines)

```
You: [degree, field, institution]
Interest: [one line]
Strengths I will lean on: [3 skills or experiences]
Target: [level, countries, term, funding]
Gaps to be honest about: [e.g. no publications, no R experience]
```

Gaps matter. If the student has no publications, the email should not pretend otherwise. It should lead with the thesis or hands-on work.
